# Taurus Labs Homebrew Tap

```sh
brew install --cask tauruslabsofficial-tech/tap/togetheraudio
```

| Cask | Description |
|---|---|
| [`togetheraudio`](Casks/togetheraudio.rb) | [TogetherAudio](https://github.com/tauruslabsofficial-tech/TogetherAudio): play your Mac's audio on several Bluetooth headphones at once |

TogetherAudio is open source (MIT) but not yet notarized by Apple, so this cask clears the download quarantine flag after installing. Without that, macOS would block the first launch. The app's source and release builds are at the link above.
